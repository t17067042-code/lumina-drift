# Lumina Drift

**Самая уникальная мобильная веб-игра 2026 года.**

Мир, который растёт вместе с тобой.  
Наклоняй телефон — меняется гравитация.  
Проводи пальцем — толкаешь свет.  
Собирай фрагменты — нейронная сеть эволюционирует, появляются аттракторы, репульсоры и порталы.

Никаких уровней. Только бесконечная эволюция твоего личного космоса.

## Как играть
1. Открой на телефоне
2. Разреши доступ к ориентации (для наклона)
3. Наклоняй устройство и проводи пальцем
4. Собирай золотые сферы света — мир будет меняться навсегда

## Технологии
- Чистый Canvas + DeviceOrientation API
- Полностью клиентская, работает офлайн
- PWA-ready (можно добавить на домашний экран)

Сделано как эксперимент «лучшая возможная игра, которой ещё не существует».
